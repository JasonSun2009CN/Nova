# ADR-0014: 航行主视角改目的地单星放大 + S25 仪表盘提前交付

- 状态: Accepted
- 日期: 2026-08-07
- 决策者: 用户（产品决策）+ 工程评审

## 背景与问题陈述

S23 首版航行主视角（按 ADR-0011 方案 A）复用 StarField 全星场 + 光行差 + 拖尾：相机立出发地星、朝目的地真实推进。实测观感差——高 γ 下光行差把整片星场压缩进中央极窄锥（β→1 时近似一个点），拖尾又使星点拉长模糊，**"看不出来是在外太空"**。

ADR-0011 的核心目标——"接近/到达有真实物理对象、到达后可见真实目的地星"——仍然成立；被否决的是"深度分层星流复用 LOD"作为主视角的渲染方式。

## 考虑过的方案

### 方案 A: 全星场 + 光行差 + 拖尾（首版，被否）

相机真实推进，整片真星场 + 相对论特效。高 γ 光行差全压缩 + 拖尾模糊，视觉退化为一个光点、缺乏深空感。用户否决。

### 方案 B: 目的地单星放大 + 暗星点阵背景（选定）

主视角 = **极暗远景真星点阵**（StarField 调暗调小，无光行差/拖尾）+ **目的地单星居中随航程线性放大**（白色核心 + 光谱色光晕）。深空感由暗星点阵承担，目标清晰可见且逐渐变大。

### 方案 C: 纯黑 + 单星

无背景星点。用户选择保留暗星点阵（有深空感），故未采纳。

## 决策

1. 航行主视角改为：暗星点阵背景（`StarField` opacity 0.3 + sizeScale 0.5）+ 目的地单星居中放大（8px → 300px 随 fraction 线性，billboard plane + glow shader，用目的星光谱色）。
2. StarField 撤销光行差/拖尾 uniform（航行不再使用），新增 `opacity` prop（背景调暗用）。
3. **S25 实时仪表盘提前到本阶段交付**：航行进度仪表（出发地→目的地两星 + 名称标注 + 金线填充）、主/客观双时间轴（船上/地球已过）、当前速度 v/c、γ、已航行/剩余距离、ETA（地球剩余）、引擎功率（γ / 当前引擎 γ_max 利用率 %）。
4. 相机推进封顶 98%（防目的地星被相机穿没、到达时仍可见）。
5. 自由漂流（无目的地）：暗星点阵 + 相机沿银道 +Z 推进，仪表盘显示"自由漂流 · 已航行距离"。

## 决策依据

1. **主视角清晰度优先**：单星放大观感干净、目标明确，暗星点阵保留深空语境，二者都不糊。
2. **仪表盘是航行进度的可视化载体**：原 S25 计划依赖引擎数据（`cruisePlan`/`VoyageController` tick），S22 后数据已具备，提前交付无阻塞。
3. **为 S24/S26 留接口**：蓝移（S24）与跃迁过渡（S26）可叠加在单星 + 暗星点阵之上，无需全星场。

## 后果

### 正面影响

- 主视角清晰：看得见目的地星随航程变大，深空感由暗星点阵承担。
- S25 仪表盘提前交付，航行进度（出发地→目的地 + 名称）可视化。
- 光行差/拖尾 shader 回退后 StarField 回归简单稳定（星图复用无回归）。

### 负面影响

- 放弃"第一人称穿越星场"的沉浸式设想（ADR-0011 原计划），近观星流留待 S26 评估。
- 光行差/拖尾 shader 代码回退删除（已单测过，属重复工作量）。

### 风险与缓解措施

| 风险                  | 影响 | 概率 | 缓解措施                                                            |
| --------------------- | ---- | ---- | ------------------------------------------------------------------- |
| 单星放大观感单调      | 中   | 中   | S24 蓝移 / S26 跃迁过渡叠加；`STAR_START_PX`/`STAR_END_PX` 集中可调 |
| 暗星点阵背景过亮/过暗 | 低   | 低   | `BG_OPACITY` / `BG_SIZE_SCALE` 集中可调                             |
| 仪表盘信息过载        | 中   | 中   | 指标集中 3×2 网格，可裁剪（用户反馈驱动）                           |

## 关联 ADR

- **修订 ADR-0011**（航行视图真实星表化）：主视角从"全星场深度分层"改为"目的地单星放大 + 暗星点阵"；其余（相机立出发地、朝目的地、三 chunk 复用、`VoyageStarFlow` 退役）不变。
- ADR-0002 图形渲染：单星用 billboard plane + 自定义 glow shader。
- ADR-0012 统一飞行模型：仪表盘引擎功率 = γ / γ_max，复用 ENGINE_TIERS。
