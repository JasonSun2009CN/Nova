# ADR-0011: 航行视图真实星表渲染（R3F 复用 renderer）

- 状态: Accepted
- 日期: 2026-08-05
- 决策者: 用户（产品决策）+ 工程评审

## 背景与问题陈述

Phase 1 航行视图使用 Canvas 2D 抽象星流（`src/components/VoyageStarFlow.tsx`，`Math.random()` 生成 140 颗随机星），**不是真实星表**。真实星表目前只在星图弹窗（`StarMapView`，R3F）里渲染。

Phase 3 规划的航行视图视觉——深度分层星流、Doppler 蓝移、跃迁接近动画"目标变大"——都隐含"航行视图渲染真实星图"的前提，但该前提在 ROADMAP 里没有写明，且代码现状并不满足：

- **Doppler 蓝移没有参考系**：抽象星流没有"前方/后方"的真实方向，偏蓝只是整体色调假象。
- **接近动画没有对象**："目标星越来越大"要求真实目标星在视野中。
- **到达没有落点**：到达后无法看到真实目的地星。

ADR-0002 从一开始就把"航行第一人称视角"规划为 Three.js 3D 场景；当前 Canvas 2D 星流是 v0.1 MVP 的临时妥协，不是架构决策。

## 考虑过的方案

### 方案 A: R3F 复用 renderer StarField（选定）

VoyageView 内嵌 R3F `<Canvas>`，相机立于当前出发地星（`currentStarId`）、看向目的地方向（`destStarId`）：

- 深度分层星流复用现有 LOD tier（近星快 / 远星慢来自真实距离，非随机）。
- 拖尾 / 光行差 / 前向蓝移在 `StarField` 现有 ShaderMaterial 上新增 uniform。
- three ~967KB chunk 在航行启动时加载，与星图弹窗共享同一 chunk（常规"设目的地 → 航行"流程弹窗已加载，无感）。

**优点:** 蓝移/接近/入轨/到达全部自洽；代码复用最高；到达显示真实目标星。
**缺点:** 航行启动引入一次 three 加载（若从未打开过星图弹窗）；渲染管线需加"方向/朝向"维度；`VoyageStarFlow` 退役。

### 方案 B: 抽象星流 + 引导光点

保留 Canvas 2D 星流，叠加一个"目的地方向光点"（接近时变大），蓝移做成全局色调。

**优点:** 轻快，不引入 three。
**缺点:** 无方向性；到达看不到真实星；蓝移无物理依据。

### 方案 C: 保持纯抽象

星流 + 整体蓝染。

**优点:** 最省。
**缺点:** "前方偏蓝"纯假象，与真实星图导航的产品定位脱节。

## 决策

采用**方案 A**：

1. VoyageView 用 R3F 复用 `StarField`，相机立于 `currentStarId` 看向 `destStarId`。
2. 深度分层复用现有 LOD；拖尾 / 光行差 / 前向蓝移在现有 ShaderMaterial 加 uniform（蓝移**只蓝不红**，后方不可见，红移不做）。
3. `VoyageStarFlow`（Canvas 2D 抽象星流）退役。
4. three chunk 复用星图弹窗的懒加载产物。

## 决策依据

1. **真实星表是产品核心**（ADR-0006 / ADR-0010）：航行体验应与星图一致，用户能"看见自己正飞向哪颗真实恒星"。
2. **兑现 ADR-0002**：航行第一人称视角本就规划为 Three.js 场景。
3. **数据通路已具备**：`progress.vOverC / gamma`（store）、`destStarId`、`currentStarId`（settings 持久化）均为现成数据。
4. **性能可控**：three chunk 已按 manualChunks 拆分且与弹窗共享；982 颗真实星远低于 WebGL 点渲染上限。

## 后果

### 正面影响

- Doppler 蓝移 / 接近动画 / 入轨 / 到达全部有真实物理对象。
- 到达后当前星更新为真实目的地星（S18 已有 `currentStarId` 更新逻辑）。
- 渲染管线与星图复用，S24 蓝移、S26 接近动画在同一套 shader 上叠加。

### 负面影响

- 航行启动首次需加载 three chunk（~967KB）；若用户未先开过星图弹窗会有一次加载等待。
- `VoyageStarFlow` 退役，其测试与样式需清理。
- 渲染层需增加"相机定位到当前星 + 朝向目的地"的逻辑，跨入星图相机 rig 的复用问题。

### 风险与缓解措施

| 风险                              | 影响 | 概率 | 缓解措施                                                      |
| --------------------------------- | ---- | ---- | ------------------------------------------------------------- |
| 航行启动 three 加载等待           | 中   | 中   | 与星图弹窗共享 chunk；弹窗已加载则无感；可预加载              |
| 低端设备 WebGL 掉帧               | 中   | 中   | S29 帧率自动降级机制；LOD 控制点数量                          |
| 相机朝向/当前位置与星图标记不一致 | 中   | 低   | 复用 `StarMapCameraRig` / `FollowStarBridge` 的定位数学与单测 |
