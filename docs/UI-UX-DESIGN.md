# Nova UI/UX 设计文档

> 星际专注软件 - 让每一次专注都成为一次宇宙旅行

---

## 1. 设计理念

### 1.1 核心隐喻

用户不是在"设置计时器"，而是在**规划一次星际航行**。

- 专注 = 飞船引擎运行时间
- 休息 = 进入空间站/行星轨道休整
- 成就 = 到达新的星系、发现新天体

### 1.2 视觉基调

| 维度       | 设计方向                                               |
| ---------- | ------------------------------------------------------ |
| **主色调** | 深空蓝 (#0A0E27) + 星云紫 (#1A0F3D) + 恒星金 (#FFD700) |
| **氛围**   | 沉浸式、宁静、浩瀚、神秘                               |
| **动效**   | 缓慢、流畅、符合物理规律（恒星运动、星云飘动）         |
| **字体**   | 现代无衬线字体，数字使用等宽字体以增强科技感           |

## 2. 核心界面设计

### 2.1 主视图 - 星图导航 (Star Map)

这是应用的默认视图，也是用户最常停留的界面。

#### 2.1.1 布局结构

```
┌─────────────────────────────────────────────────────────┐
│  [Menu]  NOVA              [定位] [搜索] [设置] [用户]  │  顶部导航栏
├─────────────────────────────────────────────────────────┤
│                                                         │
│                    🌌 宇宙星空背景                        │
│                                                         │
│           ✦  当前位置：太阳系·地球轨道                     │
│                                                         │
│              ○  半人马座α                                 │
│                                                         │
│     ✧                         ◇  天狼星                  │
│                                                         │
│                        ○  织女星                         │
│                                                         │
│  [缩放-] [缩放+]  [重置视图]  [我的航线]  [排行榜]       │  底部工具栏
└─────────────────────────────────────────────────────────┘
```

#### 2.1.2 交互细节

- **双视角（左缘按钮切换）**
  - **出发地视角**（默认）：相机站在当前位置（出发地）恒星上环视星空，拖拽即转头；圆环标记目的地。航行完成后出发地 = 上次目的地。
  - **上帝全览视角**：从远处俯瞰太阳系全貌，太阳居中，以太阳为中心的半径圈（10 / 25 / 50 光年）标注距离。
- **拖拽旋转 / 环视**：全览视角旋转星图；出发地视角环视星空
- **缩放**：滚轮/双指缩放，缩放到不同级别显示不同层级天体
  - Level 1 (最远): 星系团 → 星系
  - Level 2: 星系 → 星云/星协
  - Level 3: 恒星系统 → 行星
- **点击天体**：显示天体信息卡（名称、距离、类型、到达所需专注时长）
- **航线可视化**：用户已旅行过的路径用发光线条连接

#### 2.2.2 时间膨胀效应可视化

这是Nova的核心特色，需要**直观展示**而非仅仅显示数字：

**视觉表现方式：**

1. **星光拖尾长度变化**：速度越接近光速，星星拖尾越长
2. **星空密度变化**：前方星空被压缩（蓝移），后方被拉伸（红移）
3. **画面边缘畸变**：模拟相对论性光行差效应
4. **双时间轴显示**：
   - 上方：主观时间（用户感知的专注时间）
   - 下方：宇宙实际时间（膨胀后的时间，用于计算到达距离）

**时间膨胀公式应用：**

```
γ = 1 / √(1 - v²/c²)     # 洛伦兹因子
宇宙时间 = 专注时间 × γ
实际航行距离 = 速度 × 宇宙时间
```

#### 2.2.3 专注模式类型

| 模式         | 说明                                       | UI 表现                                    |
| ------------ | ------------------------------------------ | ------------------------------------------ |
| **定时航行** | 用户设定目标时间（如25分钟）               | 显示精确倒计时，到达目标自动完成           |
| **自由漂流** | 不设时间，用户手动结束专注                 | 显示已航行时间，支持"设定下一个天体为目标" |
| **跃迁任务** | 设定目标天体，系统根据距离计算所需专注时间 | 显示"到达XX需要YY分钟，是否出发？"         |

## 3. 视觉元素规范

### 3.1 天体视觉编码

| 天体类型             | 视觉样式                         |
| -------------------- | -------------------------------- |
| **类太阳恒星 (G型)** | 暖黄色圆形，轻微脉动光晕         |
| **红矮星 (M型)**     | 暗红色小圆形，低调               |
| **蓝巨星 (O/B型)**   | 青蓝色大圆形，强光晕             |
| **白矮星**           | 白色极小点，锐利                 |
| **中子星/脉冲星**    | 快速闪烁的亮点，射束效果         |
| **黑洞**             | 黑色圆盘 + 吸积盘光环            |
| **行星（类地）**     | 蓝色/绿色/棕色小球，有大气层辉光 |
| **行星（气态）**     | 条纹状大球，带光环（如土星）     |
| **星云**             | 半透明彩色云团，渐变模糊         |
| **星系**             | 螺旋/椭圆形态，远距离视角        |

### 3.2 动效规范

#### 3.2.1 通用原则

- **慢速美学**：默认动画时长 0.8s-2s，避免突兀
- **缓动曲线**：优先使用 `cubic-bezier(0.25, 0.46, 0.45, 0.94)` 或 `ease-out`
- **层级阴影**：界面元素投影颜色为深紫蓝色，不是纯黑

#### 3.2.2 关键动效

| 场景         | 动效描述                                              |
| ------------ | ----------------------------------------------------- |
| **启动专注** | 飞船引擎启动 → 周围星空加速 → 进入跃迁状态（3秒过渡） |
| **结束专注** | 减速动画 → 抵达目标天体 → 天体信息卡从下方滑入        |
| **中断专注** | 引擎报警红光闪烁 → 退出到最近安全港（中间位置）       |
| **星星流动** | 基于Z轴深度的视差滚动，近处星星移动快，远处慢         |
| **天体发现** | 新天体解锁时，光芒放射动画 + 音效                     |

### 3.3 音效设计（预留）

| 场景          | 声音风格                                   |
| ------------- | ------------------------------------------ |
| 引擎运行      | 低频持续嗡鸣，可调节音量或关闭             |
| 跃迁启动/结束 | 科幻感上升/下降音效                        |
| 到达新天体    | 悠扬的风铃/钟声                            |
| 专注中断      | 轻微警报（不刺耳）                         |
| 背景环境      | 可选白噪音：宇宙微波背景辐射、飞船空调声等 |

## 4. 交互流程

### 4.1 首次启动流程

```
欢迎界面（星空动画 + Nova Logo）
    ↓
简短教程（3-4个滑动卡片）：
  1. Nova是什么？—— 专注=星际旅行
  2. 选择目的地 or 设定时间
  3. 时间膨胀效应：飞得越远，专注越有价值
  4. 开始你的第一次航行
    ↓
星图视图（默认位置：太阳系）
    ↓
引导操作：高亮"半人马座α" → 点击 → "设定为目的地"
```

### 4.2 日常使用流程

```
打开应用
    ↓
查看当前位置（上次到达的星系）
    ↓
两种路径：
  ├─ 路径A：在星图上选择目标天体 → 系统计算所需时间 → 开始航行
  └─ 路径B：设定专注时间（番茄钟/自定义）→ 自动选择距离匹配的天体
    ↓
航行中：
  - 显示实时进度、速度、时间膨胀系数
  - 可选任务笔记、白噪音
  - 支持暂停（但暂停时速度降为0，不计算航程）
    ↓
到达目的地：
  - 解锁新天体
  - 记录本次航行数据
  - 显示成就徽章（如"首次跨越5光年"）
  - 可选：继续下一段旅程 or 返回主菜单
```

## 5. 状态设计

### 5.1 应用状态机

```
[空闲 Idle]
    │  选择目标/设定时间
    ▼
[准备航行 Ready]
    │  确认出发
    ▼
[航行中 Voyaging]
    │  暂停              │  中断              │  完成
    ▼                    ▼                    ▼
[暂停 Paused]       [中断 Aborted]       [到达 Arrived]
    │  继续              │  记录部分里程       │  解锁天体
    ▼                    ▼                    ▼
[航行中]            [空闲]              [空闲/继续下一站]
```

### 5.2 异常处理

- **应用被意外关闭**：下次启动时询问"上次航行中断，是否恢复？"
- **网络断开**：不影响核心功能，仅远程排行榜/云同步不可用
- **系统休眠**：休眠期间不计入专注时间，恢复时提示并重新校准

## 6. 无障碍设计

### 6.1 对比度

- 文本与背景对比度 ≥ 4.5:1 (WCAG AA)
- 深空蓝背景上使用白色/淡蓝色文字

### 6.2 动效降低

- 检测系统 `prefers-reduced-motion` 设置
- 开启后：禁用星光拖尾、简化缩放动画、使用淡出淡入代替滑动

### 6.3 字体缩放

- 支持系统字体缩放设置
- 最小可点击区域：44×44px

## 8. 未来扩展性设计

### 8.1 预留模块位

- **多人联机航行**：组队探索同一星系，好友专注状态可见
- **用户自定义星图**：上传自定义星系、命名新发现天体
- **AR模式**：手机端用摄像头叠加星空到真实环境
- **可穿戴设备同步**：Apple Watch/小米手环显示剩余时间、震动提醒

### 8.2 主题

采用**单一暗色中性主题**（见 ADR-0009）：近黑灰阶 + 金色强调色，与黑色星图天然融合。主题 Token 集中在 `src/styles/index.css` 的 `:root`，如需回归多主题可扩展 `[data-theme=...]` 块。
