## 版本策略

| 版本类型              | 说明                                      | 发布频率  |
| --------------------- | ----------------------------------------- | --------- |
| **v0.x.x (Alpha)**    | 核心功能开发期，可能存在 breaking changes | 按需发布  |

**目标**：加入真实星图，支持选择目的地
**状态**：S16 渲染 + S17 星图弹窗交互已完成；用户驱动增量：**星图双视角**（出发地视角 / 上帝全览视角）+ 以太阳为中心的半径圈 + 当前位置随航行更新；**S18 导航增量**：目的地数据源统一（真实星表唯一来源）+ 选目的地反推预计专注时长；**S19 设置页增量**：专注时长滑杆 + `cruisePlan` 反推航线（设目的地后推算所需速度与地球年）；**S20 星图搜索 + 推荐目的地**：弹窗内按常用名/HIP 编号搜索恒星（`searchStars`），设置页基于剩余专注时长推荐可达目的地（`recommendDestination`，推荐最远可达星、无可达时回退最近星）；**增量 3 变动出发地**（ADR-0013）：出发地 = `settings.currentStarId`（上次目的地），航行从当前位置出发，规划/推荐按出发地→目的地实际两星距离计算。

### 2.1 星图引擎

## 🛸 Phase 3: 完整航行系统 + 相对论视觉

**版本**：v0.3.0 (Alpha)
**目标**：实现沉浸式的第一人称航行视图，完整的时间膨胀视觉效果

### 3.1 航行视图（Voyage View）

- [ ] **第一人称飞船视角**

  - **基于真实星表渲染**（复用 R3F StarField，相机立于当前位置星、看向目的地方向；非抽象随机星流）
  - 星空向后流动，按深度分层（近星快 / 远星慢，复用 LOD）
  - 星光拖尾长度随速度增加
  - 蓝移效应：前方星空随速度偏蓝（红移已移除——后方不可见）
  - 光行差畸变：星空向视野中心压缩（相对论效应）

- [ ] **实时仪表盘**

  - 主/客观双时间轴
  - 当前速度（v/c）
  - 洛伦兹因子 γ
  - 已航行距离
  - 剩余距离 / 预计到达时间
  - 引擎功率指示器

- [ ] **跃迁过渡动画**
  - 启动：引擎点火 → 星光加速 → 进入跃迁（3s）
  - 停止：减速 → 目标天体越来越大 → 进入轨道（3s）
  - 中断：紧急刹车效果 → 停在中途位置

### 3.2 引擎等级系统

- [ ] **引擎解锁机制（γ 分级）**

  - 可达距离 ≈ γ_max × 专注时长（d = β·γ·τ，τ 为船上固有时）；引擎等级决定「同一次专注能飞多远」，单次专注即可到达恒星（见 ADR-0012）
  - 常规引擎（默认）：γ_max ≈ 100,000（25 分钟可达 ~4.8ly，比邻星级近星）
  - 曲速一级（累计 10h 专注后解锁）：γ_max ≈ 400,000（~19ly，织女/牛郎星级）
  - 曲速二级（累计 50h 专注）：γ_max ≈ 1,200,000（~57ly，覆盖整个 50ly 星表）
  - 曲速三级（累计 200h 专注）：γ_max ≈ 5,000,000（~238ly，为 500ly 扩展预留）
  - 跃迁引擎（里程碑成就解锁）：γ_max ≈ 20,000,000（~951ly，500ly 扩展全覆盖；**无瞬时到达**）

- [ ] **可达性约束**

  - 目的地 + 专注时长在当前引擎下不可达时：阻止开始，显示所需 γ、解锁路径（还需累计多少专注）、当前引擎下最短专注时长

- [ ] **任务模式**
  - 定时航行（已知）
  - 跃迁任务（选中天体 → 按当前引擎 γ_max 自动计算所需专注时长）
  - 自由漂流（已知）

### 3.3 白噪音系统

- [ ] 背景音效：引擎嗡鸣（可调节音量或关闭）
- [ ] 可选环境音：CMB 白噪音、脉冲星节奏音
- [ ] 关键事件音效：启动、到达、中断、成就解锁

### 3.4 质量保障

- [ ] 航行视图性能：60fps（帧率自动降级机制）
- [ ] 相对论数值精度测试（γ 值与公式手动计算对比）
- [ ] 长时间运行稳定性测试（连续运行 8 小时无泄漏）

**验收标准**：用户进入航行模式后，能直观感受到速度接近光速时的视觉变化，时间膨胀数字与视觉效果匹配。

## 🎢 版本发布流程

1. **功能冻结 (Feature Freeze)**：该版本范围不再新增功能
2. **RC 阶段 (Release Candidate)**：发布 vX.Y.0-rc.1，仅修复 Bug
3. **Bug 修复周**：收集并修复回归 Bug，发布 rc.2 / rc.3...
4. **正式发布**：所有 P0/P1 Bug 修复后，发布 vX.Y.0 正式版
5. **补丁版本**：后续发布 vX.Y.1 / vX.Y.2 只含 Bug 修复，不含新功能
