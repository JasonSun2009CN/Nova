# Nova · 星际专注

> 让每一次专注，都成为一次跨越星海的旅程。

---

## 🌌 项目简介

**Nova** 是一款以「星际旅行」为隐喻的专注软件，以**真实宇宙结构中的星际航行**为蓝图，提供**定时航行**、**跃迁任务**、**自由漂流**等灵活的专注模式。

当你需要专注工作/学习时，在 Nova 中设定目标时间（或选择「自由漂流」模式），你的飞船将从当前位置出发，在浩瀚星海中飞向真实存在的天体系统。根据相对论效应，飞船速度越接近光速，**时间膨胀**越显著——这意味着你专注的每一分钟，在宇宙尺度上都跨越了令人惊叹的距离。

---

## ✨ 核心特性

### 🚀 真实宇宙，科学准确

- **真实天体数据**：使用 Hipparcos / Gaia 星表数据，包含数十万颗真实恒星的位置、距离、光谱类型
- **多层级结构**：从太阳系 → 邻近恒星 → 银河臂 → 本星系群 → 室女座超星系团，逐级探索
- **相对论模拟**：严格遵循洛伦兹变换计算时间膨胀、长度收缩、光行差效应

### ⏱️ 灵活专注模式

| 模式         | 适合场景                   | 说明                                             |
| ------------ | -------------------------- | ------------------------------------------------ |
| **定时航行** | 番茄钟工作法、考试复习     | 设定 25/45/60 分钟等固定时长，自动匹配可达目的地 |
| **跃迁任务** | 有明确目标的长时段专注     | 点击星图选择目标天体，系统反推所需专注时长       |
| **自由漂流** | 冥想、创意发散、无压力专注 | 不设终点，想停就停，记录已航行的距离             |

### 🎨 沉浸式视觉体验

- 实时渲染的第一人称飞船视角，星空向后方流动
- 速度接近光速时的相对论视觉效果：星光拖尾、蓝移红移、边缘畸变
- 每个天体根据光谱类型呈现独特的色彩和光晕
- 白噪音引擎：宇宙背景辐射、引擎嗡鸣、可选环境音

### 📊 航行日志与成就

- **船长日志**：按日/周/月统计专注时长、航行距离、发现的天体
- **航线地图**：可视化展示你在银河系中的探索足迹
- **成就系统**：
  - 🏅 首次跨出太阳系
  - 🌟 发现第一颗系外行星
  - 🌌 累计航行 100 光年
  - ⚫ 抵达黑洞（长时专注挑战）

## 🛠️ 技术栈

| 层级           | 技术选择                                | 说明                                    |
| -------------- | --------------------------------------- | --------------------------------------- |
| **前端框架**   | React 18 + TypeScript                   | 类型安全，组件化开发                    |
| **图形渲染**   | WebGL 2.0 (Three.js) + Inline SVG       | 高性能 3D 星空 + 精准 UI 图形           |
| **状态管理**   | Zustand                                 | 轻量、简洁，无需 Redux boilerplate      |
| **样式方案**   | Tailwind CSS + CSS Variables            | 快速迭代 + 单一暗色中性主题（金色强调） |
| **构建工具**   | Vite                                    | 极速 HMR，原生 ESM                      |
| **数据持久化** | IndexedDB (Dexie)                       | 离线可用，存储星图缓存和航行记录        |
| **单元测试**   | Vitest + React Testing Library          | Vite 原生集成                           |
| **E2E 测试**   | Playwright                              | 跨浏览器端到端验证                      |
| **包管理**     | pnpm                                    | 严格依赖，节省磁盘空间                  |
| **代码质量**   | ESLint + Prettier + Husky + lint-staged | 提交前自动检查和格式化                  |

## 🚀 快速开始

### 环境要求

- Node.js ≥ 18
- pnpm ≥ 8

### 安装与启动

```bash
# 1. 克隆仓库
git clone git@github.com:JasonSun2009CN/Nova.git
cd Nova

# 2. 安装依赖
pnpm install

# 3. 启动开发服务器
pnpm dev

# 4. 浏览器打开 http://localhost:5173
```

### 常用脚本

```bash
pnpm dev          # 启动开发服务器
pnpm build        # 生产构建
pnpm preview      # 预览构建产物
pnpm lint         # ESLint 检查
pnpm format       # Prettier 格式化
pnpm typecheck    # TypeScript 类型检查
pnpm test         # 单元测试
pnpm test:e2e     # E2E 测试
pnpm prepare      # 安装 git hooks (首次 clone 后自动执行)
```

## 🧭 核心概念

### 时间膨胀效应

Nova 的灵魂在于**将专注时长按相对论放大**。当飞船以 0.99c 飞行时：

```
洛伦兹因子 γ = 1 / √(1 - 0.99²) ≈ 7.09

用户专注 1 小时 → 宇宙实际经过 ~7.09 小时
→ 实际航行距离 ≈ 7.09 光时 ≈ 0.0008 光年
→ 足以跨越太阳系内的行星际旅行
```

更长的专注时间和更高的引擎等级，将带你飞向更远的星辰大海。

### 星层层级

为了兼顾性能和科学准确性，星图采用 LOD (Level of Detail) 分层：

| 层级 | 缩放级别 | 显示内容                                     | 数据量     |
| ---- | -------- | -------------------------------------------- | ---------- |
| L0   | 最远距离 | 本星系群中的主要星系（仙女座、大小麦哲伦等） | ~100 个    |
| L1   | 远距离   | 银河系内主要星协、星云、银河结构             | ~1000 个   |
| L2   | 中距离   | 距离 500 光年内的亮星（Hipparcos 星表）      | ~10,000 颗 |
| L3   | 近距离   | 距离 50 光年内的全部恒星系统                 | ~1,800 颗  |
| L4   | 最近     | 太阳系行星、卫星、小行星                     | ~100 个    |

## 📱 用户使用指引

### 快速开始（v0.1 MVP）

1. 打开 Nova，在「规划一次星际航行」面板选择专注时长（预设 5 / 15 / 25 / 45 分钟，或自定义）
2. 可选：选择目的地恒星（比邻星、天狼星等），或保持「自由漂流」
3. 点击「启动航行」→ 进入航行视图，星空开始流动，倒计时开始
4. 专注期间可暂停 / 继续，随时可「结束」（中止本次航行）
5. 倒计时归零自动完成 → 查看本次航行距离与时间膨胀数据
6. 「回到首页」→ 航行日志记录本次航行；**刷新页面数据不丢失**

### 安装为 App（PWA）

Nova 支持离线使用，可像原生 App 一样安装到主屏幕：

| 平台       | 步骤                                                   |
| ---------- | ------------------------------------------------------ |
| iOS Safari | 打开页面 → 分享按钮 → 「添加到主屏幕」                 |
| Android    | 打开页面 → 浏览器菜单 → 「安装应用」或「添加到主屏幕」 |

安装后可从主屏幕图标直接启动，支持**离线打开**。

### 离线与后台

- 首次联网打开后，Nova 会缓存应用外壳；之后即使断网也能正常启动和使用核心专注功能。
- 航行记录保存在本地设备，不会上传到任何服务器。
- 专注时切到后台，计时依然准确（由 Web Worker 驱动，后台误差 < 2 秒）；意外关闭页面后，下次打开会自动恢复未完成的航行。
